Academic Project 2025 – 2026

Sistem Reservasi Aurora Beauty Salon

Web-based reservation information system with a two-stage transaction flow: 50% down payment (DP) upon booking, and final payment after the service is completed. Each payment stage undergoes admin verification, and customers must check-in upon arrival at the salon before the service begins.

Technical Insight: Based on the users table structure (columns two_factor_secret, remember_token), this system is built on Laravel with Jetstream/Fortify auth scaffolding highly relevant for testing cookie-based sessions and 2FA features.

User Stories

As a Customer
US-P01

As a customer, I want to register and login so that I can access the reservation services.

US-P02

As a customer, I want to view the service list so that I can choose the desired treatment.

US-P03

As a customer, I want to check my reservation history so that I know my past bookings status.

US-P04

As a customer, I want to select a service and time slot so that my reservation fits my schedule.

US-P05

US-P06

US-P07

As a customer, I want to complete the final payment after the service is done so that my transaction is settled.

As an admin, I want to verify down payments and final payments so that no fraudulent transactions pass through.

US-A02

As an admin, I want to confirm customer arrivals so that services are only provided to legitimate customers.

US-A03

As an admin, I want to view transaction reports to monitor business performance.

US-A04

QA Learnings & Notes

State Inconsistency

The two-stage payment flow (DP ? Final) is prone to state inconsistency if admin verification is missed crucial to ensure reservation status cannot "skip" to the next phase.

Employee Involvement

Employees are not system actors, so validating "service provided" relies on manual admin/system input a critical point worth testing with negative scenarios.

Double Booking

Double booking prevention on time slots is a critical area, especially for concurrent request scenarios (two customers booking the same slot simultaneously).

Academic Project Selenium + Python

Aurora Beauty Salon Automated Test Suite

Automated test suite for critical paths in the Aurora Beauty Salon reservation system. Prioritized on the Login and Reservation + DP Payment flows because both are critical paths if either fails, the entire transaction cycle (up to final payment) is disrupted. I also included a test scenario for attempting to book a filled slot (double booking prevention).

Setup & Login Automation (TC-03 & TC-04)

test_login_aurora.py
# requirements: selenium, pytest, webdriver-manager import pytest from selenium import webdriver from selenium.webdriver.common.by import By from selenium.webdriver.support.ui import WebDriverWait from selenium.webdriver.support import expected_conditions as EC BASE_URL = "https://staging.aurorabeautysalon.example.com" @pytest.fixture def driver(): drv = webdriver.Chrome() drv.get(f"{BASE_URL}/login") yield drv drv.quit() def test_login_dengan_kredensial_valid(driver): driver.find_element(By.NAME, "email").send_keys("pelanggan_test@example.com") driver.find_element(By.NAME, "password").send_keys("Password123!") driver.find_element(By.ID, "btn-masuk").click() WebDriverWait(driver, 10).until(EC.url_contains("/dashboard")) assert "dashboard" in driver.current_url def test_login_dengan_password_salah(driver): driver.find_element(By.NAME, "email").send_keys("pelanggan_test@example.com") driver.find_element(By.NAME, "password").send_keys("passwordsalah") driver.find_element(By.ID, "btn-masuk").click() error_message = WebDriverWait(driver, 10).until( EC.visibility_of_element_located((By.CLASS_NAME, "alert-error")) ) assert "Email/Password Salah" in error_message.text

Reservation & DP Payment (TC-05 & TC-07)

test_booking_dp.py
def test_reservasi_dan_pembayaran_dp(driver): # asumsi driver sudah dalam kondisi login driver.get(f"{BASE_URL}/layanan") driver.find_element(By.LINK_TEXT, "Perawatan Wajah").click() driver.find_element( By.XPATH, "//div[@data-layanan='facial-glow']//button[text()='Pilih']" ).click() driver.find_element(By.CSS_SELECTOR, "[data-slot='10:00']").click() driver.find_element(By.ID, "btn-kirim-reservasi").click() WebDriverWait(driver, 10).until( EC.visibility_of_element_located((By.ID, "form-konfirmasi-reservasi")) ) driver.find_element(By.NAME, "catatan").send_keys("Reservasi test otomatis") driver.find_element(By.ID, "btn-bayar-dp").click() konfirmasi = WebDriverWait(driver, 15).until( EC.visibility_of_element_located((By.ID, "label-konfirmasi-pembayaran")) ) assert "Pembayaran DP Diterima" in konfirmasi.text
